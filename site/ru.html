Семь этапов метода

01 / FRAME · VBQ

Validated Business Question

Формулируем вопрос, границы, дату и критерии решения.

Gate: Вопрос, границы и критерии определены.

02 / MODEL · MVTC

Minimum Viable Trusted Context

Моделируем минимально достаточный контекст: объекты, связи, правила, неизвестное.

Gate: Модель минимальна и достаточна.

03 / BUILD · TCBS

Trusted Context Build Snapshot

Реализуем и проверяем READ → PLAN → APPROVE → WRITE → READ BACK → COMPARE.

Gate: READ BACK соответствует утверждённому плану.

04 / GROUND · GCP

Grounded Context Package

Привязываем Claim к Source, точному Evidence и Rule/Warrant.

Gate: Основания прослеживаемы, пробелы отмечены.

05 / CONNECT · TCAC

Trusted Context Access Check

Доказываем фактический доступ, полученные идентификаторы и полномочия.

Gate: Фактический доступ подтверждён.

06 / VERIFY · VRP

Verification Result Package

Проверяем выводы, правила, противоречия и ограничения.

Gate: Выводы обоснованы, ограничения явны.

07 / DECIDE · DSP

Decision & Scope Package

Фиксируем действие, полномочия, обоснование и следующего ответственного.

Gate: Действие соответствует полномочиям.

Три независимых измерения контроля

Эпистемический статус

KNOWN · DERIVED · INFERRED · UNKNOWN · CONFLICTED

Делегирование

AUTO · REVIEW · HUMAN

Решение

ACT · REQUEST EVIDENCE · ESCALATE · STOP

KNOWN ≠ ACT · UNKNOWN ≠ FALSE · RETRIEVED ≠ GROUNDED ≠ VERIFIED
